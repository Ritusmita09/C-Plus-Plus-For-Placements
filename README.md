## Learning Workflow

1. Pick one topic and solve at least 2-3 questions.
2. Add clean, readable C++ solutions with comments only where needed.
3. Commit daily using the standard workflow below.
4. Push to GitHub to keep your preparation visible and consistent.

## Daily Git Workflow (Use This Every Time)

```bash
git add .
git commit -m "<clear message>"
git push
```

Example commit messages:

- `solve: two pointer problems on arrays`
- `feat: add binary search templates`
- `docs: add graph traversal notes`

## Commit Message Style

Use simple prefixes to keep history professional:

- `feat:` for new implementations
- `fix:` for corrections
- `refactor:` for code cleanup
- `docs:` for notes and documentation
- `solve:` for solved problem sets
